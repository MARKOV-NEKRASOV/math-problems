# Fermat–Catalan: simultaneous output-prime compatibility and a Chebotarev obstruction

**25 October 2026 (Buenos Aires) — mathematical research note, not a full proof.** This is a follow-up to [prime-output-trace-sieve.md](prime-output-trace-sieve.md). The named elliptic-curve models were checked against Freitas–Naskręcki–Stoll, [arXiv:1703.05058v3, p. 6, Lemma 2.3](https://arxiv.org/pdf/1703.05058). The computations can be repeated with [seven_curve_trace_sieve.py](seven_curve_trace_sieve.py). No claim of novelty relative to the full literature or of independent refereeing is made.

## The global comparison curve stays fixed

Suppose positive primitive integers satisfy

```
a^2 + b^3 = c^p,     p prime >=11.
```

The cited lemma and irreducibility proposition give a **single** comparison elliptic curve F, from the set

```
27a1, 54a1, 96a1, 288a1, 864a1, 864b1, 864c1,
```

with the mod-p Galois module of a small quadratic twist of the Frey curve isomorphic to F[p]. Therefore, for **every** prime q >= 5 with q | c and q != p,

```
p | (q+1-a_q(F))(q+1+a_q(F)).                   (1)
```

The same F must satisfy (1) for *all* such q. One cannot vary the comparison curve independently from one output prime to another. This observation produces a finite, verifiable compatibility test for any specified finite subset of prime divisors of c.

All seven models, in the Weierstrass format [a1,a2,a3,a4,a6], are in the cited paper:

```python
CURVES = {
    '27a1':  (0, 0, 1, 0, -7),
    '54a1':  (1,-1, 0,12,  8),
    '96a1':  (0, 1, 0,-2,  0),
    '288a1': (0, 0, 0, 3,  0),
    '864a1': (0, 0, 0,-3,  6),
    '864b1': (0, 0, 0,-24,48),
    '864c1': (0, 0, 0,24,-16),
}
```

For q >= 5, the Frobenius trace can be computed with the exact character sum

```
a_q(F) = -sum_{x in F_q} chi_q((a1*x+a3)^2+4*(x^3+a2*x^2+a4*x+a6)).
```

This identity follows by completing the square in y for a generalized Weierstrass equation, and independently agrees with direct finite-field point counts.

## Two finite-support exclusions

For q = 7 the seven traces, in model order shown above, are

```
q =  7: [-1, -1, -4, 0, -3, -3, 1].
```

For every prime p >= 11, p != 7, (1) holds for some F **only** when p=11 and F is 864a1 or 864b1. It follows that if 7|c, we necessarily have p=11 and F in this two-element subset.

For q=13, q=17 and q=19, the traces are

```
q = 13: [5,-4,-2,-6,0,-3,1].
q = 17: [0, 0,-6,-8,4,-2,-6].
q = 19: [-7,2,-4,0,-6,3,-5].
```

Substituting p=11 into (1):
- At q=13, only F=864b1 is compatible.
- At q=17, only F=864a1 is compatible.
- At q=19, only F=54a1 is compatible.

The comparison curve F cannot be changed after considering q=7. Hence:

**Proposition 1.** Every primitive positive solution a²+b³=cᵖ with prime p>=11 satisfies

```
7*19 does not divide c.
7*13*17 does not divide c.
```

*Proof.* If 7 divides c then p=11 and F is 864a1 or 864b1. If 19 also divides c, the sole allowable F is 54a1, a contradiction. If both 13 and 17 additionally divide c, the first requires 864b1 and the second requires 864a1, a contradiction. The case q=p never enters: the factor 7 forces p=11 and 7,13,17,19 are then all distinct from p. QED.

**Proposition 2.** If 5|c, there is no such solution for p>=11. Indeed the Hasse bound implies p <= (sqrt(5)+1)^2 < 11 for q=5, which contradicts p>=11. This is a simple special case of the earlier general trace bound. (The q=5 character table is unnecessary for this deduction.)

These restrictions apply to *divisors* of c, not to any of the integers a, b separately. They concern the special signature (2,3,p), not the whole Fermat–Catalan conjecture.

## Why no finite prime sieve can provide the missing uniform support bound

Fix one of the seven comparison curves F and any prime p>=11. Put K=Q(F[p]), the finite Galois extension generated by coordinates of the p-torsion points of F. By the Chebotarev density theorem, infinitely many rational primes q split completely in K. After omitting the finitely many bad-reduction primes and q=p, Frobenius acts as the identity on F[p] at each such q. Accordingly

```
a_q(F) = 2 (mod p),    q = 1 (mod p)
```

(the determinant of Frobenius is q modulo p). Thus

```
p | (q+1-a_q(F)).
```

**Proposition 3.** For **every** fixed (F,p), there are infinitely many primes q>=5, q!=p satisfying (1). In particular (1), even for a specified comparison curve F, does **not** force the output c to be supported on one fixed finite set of primes.

This is only a limitation of a **necessary local condition**. The primes supplied by Chebotarev are not asserted to divide c for any solution, and the existence of infinitely many compatible primes is not evidence for the existence of any Fermat–Catalan solutions.

## The attempted contradiction and the unsolved step

Suppose infinitely many distinct primitive positive powered triples exist in the (2,3,p) family. Darmon–Granville fixed-signature finiteness forces their prime exponents p to be unbounded. The bounds p <= (sqrt q+1)^2 imply every q>=5 dividing the corresponding c must also tend to infinity along such a sequence; the fixed-output-support lemma excludes an infinite subsequence supported on a fixed finite S. The joint-prime compatibility exclusions above remove some candidate supports, but Proposition 3 shows why the trace sieve alone cannot turn the escaping prime supports into a contradiction. We require global arithmetic information—e.g. a uniform rational-point theorem for the corresponding modular curves—not yet supplied by this project.

Even a complete solution of this (2,3,p) family would not settle the other all-prime hyperbolic signatures.
